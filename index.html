Before the first prompt: what leaves this Mac

O'Mono makes one outbound request on your behalf, and only when you ask for it: the model call, carrying what you chose to send after the local checks ran.

The local checks run before anything is sent, so they can stop a transmission. The interpretation call, however, is itself a transmission: the model that classifies your material has already received it. Only the local checks can prevent something leaving outright.

Your record, the translation manual, recovery, the matter list, redaction maps and verification checklists never leave. There is no O'Mono server.

Your Anthropic API key

Your key is kept on this device, in ordinary browser storage for this site — not encrypted, and not the Mac's Keychain. O'Mono sends your requests directly to Anthropic using your account, which pays for the model calls. Clearing the key removes it from this device.
